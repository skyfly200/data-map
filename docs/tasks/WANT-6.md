# WANT-6 A dashboard worth landing on

The default view is thin. Interesting state — observation counts, freshness, enrichment status, what is worth looking at today — is scattered across pages a member has to go find.

Needed: more widgets and better ones — totals and recency, a small map or heat preview, enrichment coverage (from the reframed Coverage page), recent jobs and datasets, maybe a "finds like today's conditions" prompt once the model can answer it. The work is partly which widgets (each has to answer a real question, not decorate), partly the layout that makes them read as one view, and partly shared state so a widget reflects the same filters the rest of the app is under.
